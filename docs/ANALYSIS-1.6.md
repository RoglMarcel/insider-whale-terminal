# Analysis 1.6

## Delivery and coverage

The **Analyse** tab is independent of alerts. Desktop retrieves a selected stock
on demand. The website reads per-stock JSON generated by GitHub's scheduled
scraper; it needs no API server or API key. Search suggestions match company names
and exchange-qualified tickers, with keyboard selection. The optional local
analysis server remains available for development only.

`npm run analysis:catalogue` discovers US companies (market cap at least USD 300M,
excluding shell companies and special securities) and the first 500 listings by
market cap from each configured international exchange directory. Initial
discovery found about 8,600 listings; this is broad coverage, not every security in
every market. International cross-listings can represent the same company.
Supported adapters cover more than 20 exchange suffixes; the scheduled directory
currently selects twelve major markets. No penny-stock coverage is promised.

Each scheduled run refreshes up to 3,000 due stocks within 40 minutes, using two
workers and a delay between requests. A source rate limit stops collection for
that run. Checkpoints preserve progress every 100 stocks. Code pushes publish
the existing catalogue immediately; scheduled/manual runs collect new data.
The morning schedule also runs on weekends. The collector
preserves successful prior observations on source failure. The catalogue has an
18-hour refresh threshold; rotation or blocked sources can make individual data
older. Original observation times remain visible. Valuations older than a day
receive no current purchase assessment. GitHub Actions cache and the public
compressed cache preserve history across runs. Failed collection must not create
fake fresh data. The initial compressed public dataset is a release seed.

## Quote correction

Actual Yahoo chart metadata supplies regular-session price, exchange, name,
currency and quote time. Prices can be delayed and are not after-hours prices.
Market capitalization divided by rounded shares is no longer used as a quote.
Pence/cents are converted to major currency units. Financial statement currency
must match the quote currency; otherwise the value comparison is withheld.

## Valuation correction

The prototype capped *all* forecasts at 3% and projected current net borrowing
forever. Both made the cashflow scenario misleading. Version 2 now uses the lower
available EPS/revenue growth forecast as a cashflow **proxy**, conservatively
capped at 25%, for three years, then fades it over seven years to 2.5%. Only
missing forecasts use a 2% fallback. Raw forecasts remain visible. This proxy is
not direct FCF guidance; its cap is policy, not an empirical estimate.

Normalized equity cashflow uses FCF per share with neutral future net borrowing,
without adding cash again. Default equity discount is 10%, with bear/base/bull
sensitivities: growth ±5 percentage points, discount +2/−1.5 points, terminal
growth 2%/2.5%/3%. A sourced cost of equity can replace the default; WACC cannot.
Cashflow models use the explicit EV/equity bridge where appropriate. Token
dividends are not used to represent the entire value of a low-payout company.

The entry threshold applies the level-dependent safety discount **once to the
central estimate**, not again to an already stressed lower bound: 40%, 30%, 20%,
15% at levels 1–4. Missing basis stays unavailable and score-neutral. Analyst
targets are shown separately and do not become intrinsic value.

Scheduled peer multiples use same-day, same-industry observations with at least
five other companies per ratio, positive values, and documented outlier cutoffs.
Models do not gain accuracy simply by being numerous. Stages 3–4 require more
specific sourced inputs than generic public financial tables normally provide.
Historical inflation adjustments, option projects, independent asset appraisals,
tax shields and segment-specific valuations remain explicit missing inputs.
Industrial FCF models are excluded for identified banks, insurers and credit
services; generic FCF cannot represent their lending and regulatory capital.

## Reference comparisons

The user-supplied NVDA sources disagree because their methods and dates differ:

- [ValueInvesting.io](https://valueinvesting.io/NVDA/valuation/fair-value): Lynch earnings-growth formula, observed 199.26 USD (October 1, 2026).
- [Simply Wall St](https://simplywall.st/stocks/us/semiconductors/nasdaq-nvda/nvidia/valuation): DCF, observed 303.10 USD.
- [Alpha Spread](https://www.alphaspread.com/security/nasdaq/nvda/summary): DCF base case, observed 190.54 USD; separate multiples estimate 293.17 USD.
- [Public.com](https://public.com/stocks/nvda/forecast-price-target): analyst target, observed 329.78 USD, not intrinsic value.

These are comparison references, not hardcoded targets or calibration inputs.
No model was adjusted to force agreement with one provider.

## Verification

Tests cover perpetuity identities, enterprise/equity bridges, proxy versus raw
growth, financing normalization, safety margin, option benchmark, quote identity,
pence conversion, search filtering, inert directory parsing and K/M/B/T formatting.
Live sampling and browser checks are performed before publishing releases.
